# GlobalWebDevs Agency Website

A responsive React landing page for a web development agency, including services, selected work, process, and an enquiry form.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The form currently provides a client-side confirmation. Connect the submit handler in `src/App.jsx` to your preferred form provider or API for production submissions.
